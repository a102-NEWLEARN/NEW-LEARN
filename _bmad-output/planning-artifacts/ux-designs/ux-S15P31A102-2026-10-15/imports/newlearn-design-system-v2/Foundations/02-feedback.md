# Feedback

피드백은 사용자의 입력에 대한 즉각적인 반응입니다. 요소를 누를 수 있다는 것과, 누른 입력이 전달되었다는 것을 알려줍니다. State의 pressed 상태를 눈과 손으로 알아챌 수 있게 드러내는 역할입니다.

| 요소 | 전달 방식 |
| --- | --- |
| Color | 눌린 동안 표면 색이 바뀜 — 누를 수 있는 모든 요소의 기본 |
| Scale | 눌린 동안 정해진 거리만큼 작아짐 — 구조가 허락할 때 더함 |
| Haptic | 누른 순간 진동 — 팀에서 필요에 따라 정의 |

## 원칙

**하나의 반응으로 읽히게.** 색 전환과 축소의 시작 시점이나 속도가 다르면 반응이 둘로 나뉘어 보입니다. 그래서 두 시간 토큰(`duration-color-transition`, `duration-pressed-scale`)은 모두 150ms(`duration-d3`)로 같습니다.

**어떤 환경에서도 반응을 남기기.** 축소는 동작 줄이기 설정에서, 햅틱은 기기에 따라 빠질 수 있습니다. 색 전환은 설정의 영향을 받지 않으므로 기본 요소로 두고, 나머지를 그 위에 더합니다.

## Color — 눌린 색

- 눌린 색은 새로 만들지 않고, 기본 토큰 이름 뒤에 `-pressed`가 붙은 짝을 씁니다. 예: `bg-neutral-weak` → `bg-neutral-weak-pressed`, `bg-brand-solid` → `bg-brand-solid-pressed`.
- 색은 **표면에서만** 바뀝니다. 표면 위 텍스트·아이콘 색은 그대로 두며, 전경용 pressed 토큰은 없습니다.
- 평소 배경이 없는 요소(ghost 버튼 등)는 누르는 동안 `bg-transparent-pressed` 표면이 생깁니다. floating layer 위의 요소라면 `bg-layer-floating-pressed`를 씁니다.
- 색이 이미 상태를 나타내는 요소(Switch의 켜짐/꺼짐, 탭의 선택/비선택)는 눌림에 색을 쓰지 않고 축소만 씁니다.

## Scale — 눌림 축소

SEED는 축소를 배율이 아니라 **거리**로 정의합니다. 고정 배율(예: 0.98)은 요소가 넓어질수록 가로로 움직이는 양이 커지기 때문입니다(343px 폭이면 6.9px, 720px 폭이면 14.4px). 눌린 요소는 세로로 2px 줄어들고, 배율은 실제 크기에서 계산합니다.

```
basis = max(요소 높이, 요소 폭 ÷ 4, 24)
scale = (basis − 2) ÷ basis
```

| 요소 | 크기 | basis | scale |
| --- | --- | --- | --- |
| 아이콘 버튼 | 32 × 32 | 높이 32 | 0.938 |
| 텍스트 버튼 | 120 × 48 | 높이 48 | 0.958 |
| 가로로 긴 버튼 | 343 × 48 | 폭÷4 = 85.75 | 0.977 |
| List Item | 375 × 60 | 폭÷4 = 93.75 | 0.979 |
| 작은 버튼 | 22 × 22 | 최소 24 | 0.917 |

축소량 2, 폭 보정 4, 최소 basis 24는 모든 화면에서 고정이며 요소나 서비스마다 바꾸지 않습니다. 축소는 항상 요소 정가운데를 기준으로 하고, 주변 요소의 자리를 밀지 않습니다(`transform: scale()`). 곡선은 `timing-function-pressed-scale`, 시간은 `duration-pressed-scale`.

직접 만드는 요소에 적용할 때는 세 가지를 확인합니다.

1. **적용할지** — 영역이 하나의 면으로 잡히는 요소에만 씁니다. 문장 안의 링크 텍스트에는 쓰지 않습니다. 카드 열기·좋아요·저장처럼 대등한 동작이 나란히 있으면 전체가 아니라 실제로 누른 타깃만 반응합니다.
2. **무엇을 줄일지** — 전체를 줄여도 정렬·여백·모서리가 어긋나지 않으면 요소 전체(Root Scale, 예: Action Button). 화면 폭을 채우는 List Item·Accordion처럼 어긋나 보이면 콘텐츠만(Content Scale).
3. **중첩** — 이미 축소되는 요소 안에 있으면 안쪽 요소의 축소는 끕니다(배율이 곱해지므로).

Selected 상태도 누르면 축소되고 선택 색은 유지합니다. Loading 중에는 축소하지 않습니다.

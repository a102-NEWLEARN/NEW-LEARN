# Logos

NEW:LEARN 로고 6종입니다. 브랜드 가이드의 형태(L자 받침 + 연결된 두 노드, NEW:LEARN 워드마크)를 그대로 따라 플랫한 2색 벡터로 다시 그렸습니다. 모두 배경이 투명한 SVG입니다(ZIP에는 4배 크기 PNG도 함께 있습니다).

| 파일 | 색 | 놓을 배경 |
| --- | --- | --- |
| `newlearn-logo-horizontal.svg` | 막대·노드 민트 #28CDAA, 받침 차콜 #222B30, 워드마크 차콜, 콜론 민트 | 흰색·Background Subtle 등 밝은 배경 — 기본 |
| `newlearn-logo-horizontal-slogan.svg` | 위 + 슬로건 #66717A | 밝은 배경, 소개·표지 |
| `newlearn-logo-vertical.svg` | 세로형, 슬로건 포함 | 밝은 배경, 정사각형 공간 |
| `newlearn-logo-mono-dark.svg` | 차콜 #222B30 한 색(막대와 받침 사이 3px 틈) | 밝은 배경, 한 가지 색만 쓸 때 |
| `newlearn-logo-reversed-white.svg` | 막대·노드·콜론 민트, 받침·워드마크 흰색 | 차콜 #222B30·진한 청록 #087F72·사진 등 어두운 배경 |
| `newlearn-symbol.svg` | 막대·노드 민트, 받침 차콜 | 밝은 배경, 파비콘·좁은 공간 |

- 최소 크기: 가로형 높이 20px, 심볼 16px. 노드 연결선이 이 크기에서도 보이도록 원본보다 조금 굵게 그렸습니다.
- 여백: 로고 주변에 심볼 높이의 1/4 이상을 비웁니다(원본 규정이 있으면 그 값을 따릅니다).
- 밝은 민트 바탕 위에는 흰 로고 대신 차콜 단색을 씁니다.
- 색을 바꾸거나 비율을 늘이지 않고, 워드마크를 다른 글꼴로 다시 쓰지 않습니다.
- 워드마크는 Poppins ExtraBold, 슬로건은 Pretendard Medium(둘 다 OFL) 윤곽선입니다. 원본 글꼴과 원본 심볼 벡터를 받으면 같은 이름으로 교체합니다.

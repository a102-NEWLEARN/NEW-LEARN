# App-Icons

NEW:LEARN 앱 아이콘 3종입니다. 로고 심볼을 플랫한 2색으로 올리고, 모서리를 둥글게(반경 22.5%) 처리한 SVG입니다(ZIP에는 1024px PNG도 함께 있습니다).

| 파일 | 바탕 | 심볼 |
| --- | --- | --- |
| `newlearn-app-icon-color.svg` | 민트 #28CDAA | 차콜 #222B30 한 색 — 민트 위에 흰색을 쓰지 않음 |
| `newlearn-app-icon-dark.svg` | 차콜 #222B30 | 막대·노드 민트, 받침 흰색 |
| `newlearn-app-icon-light.svg` | 흰색 | 기본 심볼(민트 + 차콜) |

- 기본은 컬러(민트 바탕)입니다. 흰 바탕이 어울리는 곳(웹 공유 카드, 문서)에는 라이트를 쓰고, 흰 화면 위에 놓을 때는 1px `stroke-neutral-weak` 테두리로 경계를 보여주세요.
- 스토어 제출용은 OS가 모서리를 자르므로, 원본 SVG에서 둥근 모서리 사각형을 빼고 정사각형으로 내보내야 합니다.

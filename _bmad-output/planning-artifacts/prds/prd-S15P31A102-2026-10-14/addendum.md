# 뉴런(NEW:LEARN) PRD 부록

PRD 본문에 넣기엔 구체적이지만, 설계·개발 단계에서 필요한 내용을 모아 둔다.

## 팀 구성과 역할

| 역할 | 담당 |
| --- | --- |
| PM | 장민준 |
| Design, FE | 안서진 |
| AI | 강유진, 황도경 |
| BE | 강하린, 김주우 |
| Infra | 김주우 |

## 데이터 소스 계획 (미정)

| 시나리오 | 학습·평가 | 서비스 데이터 |
| --- | --- | --- |
| 기본안 | SSAFY 뉴스 데이터셋 | 빅카인즈(BigKinds) API |
| 대안 | SSAFY 뉴스 데이터셋 | 직접 크롤링 |

서비스 데이터 소스가 정해지면 아키텍처 단계에서 수집 주기, 저장 범위(본문 전체인지 일부인지), 라이선스 조건을 다시 확인한다.

## 기획 배경 메모

취업 준비를 하다 보면 삼성처럼 시사 이슈를 묻는 자소서 문항이 있고, 면접을 앞두고는 지원 산업의 최신 뉴스를 파악해야 한다. 이때 여러 곳에 흩어진 뉴스를 시간 순서로 따라가기 어렵다는 경험이 출발점이다.

## SSAFY 뉴스 데이터셋 구조

현재 학습·평가에 쓸 SSAFY 데이터셋의 필드다.

| 필드 | 타입 | 의미 | 비고 |
| --- | --- | --- | --- |
| company | text | 언론사 | |
| title | text | 기사 제목 | |
| link | text | 원문 링크 | 별도 ID가 없어 고유 키 후보 |
| published | text | 발행일 | `2023-07-12 15:53` 형식의 문자열. 날짜 타입 변환 필요 |
| category | text | 세부 카테고리 | 예: `경제 일반` |
| category_str | text | 전체 카테고리 경로 | 예: `HOME\| 경제\| 경제 일반`. 7개 상위 카테고리는 여기서 뽑는 것으로 보임 |
| reporter | text | 기자명 | 예: `김민정 기자` |
| article | text | 본문 전체 | 줄바꿈으로 문단 구분 |

### 샘플 기사로 본 추출 예시

여성신문, 2023-07-12, 「40대 여성 CEO 김유진, '실적 부진' 한샘의 구원투수될까」

| 추출 항목 | 값 |
| --- | --- |
| 인물 | 김유진(42, IMM오퍼레이션즈본부장 → 한샘 신임 대표 내정), 김진태(현 대표), 조창걸(창업자) |
| 기관 | 한샘, IMM PE, 롯데쇼핑, 에이블씨엔씨 |
| 사건 | 한샘 신임 대표 내정 |
| 시점 | 2023-07-12 내정 보도, 2023-07-13 이사회 의결 예정 |
| 배경 | 부동산 경기 침체로 인테리어 수요 급감, 2022년 영업손실 217억 원(상장 후 첫 적자), 주가 22만 원대 인수 → 4만 원대 |
| 결과·전망 | 13일 이사회에서 선임 예정, 실적 회복 여부 주목 |
| 해석(사실과 구분) | "실적 부진 때문에 김진태 대표가 물러나는 것 아니냐는 해석도 나온다" |

마지막 줄처럼 기사에는 사실과 해석·전망이 섞여 있다. 주장 변화 분석(F09)에서 이 둘을 구분하지 않으면 "해석"이 "사실 상충"으로 잘못 판정될 수 있다.

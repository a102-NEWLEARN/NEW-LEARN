# 뉴런 사건·이슈 판정 기준

- 버전: v4 (2026-11-03)
- 작성: 유진 · 민준 (1·2차 라벨링 논의), 도경 의견 반영
- 범위: 정답셋을 만들 때 쓰는 **판정 기준**만 담는다. 테스트셋 구성·지표·통과 기준은 별도 평가 문서에 둔다
- 표시: **[확정]** 팀 합의 완료 · **[제안]** 도경 제안, 회의에서 확정 필요
- v4에서 바뀐 것: 11/3 회의에서 논의 예정 A~H를 도경 의견대로 확정했다. 바뀐 문장 끝에 (A)~(H)를 달았고, 새 기준으로 다시 판정할 쌍은 4-4에 모았다

## 0. 파이프라인에서 이 기준이 쓰이는 곳

```
기사
 │
 ▼
① 사건 추출 EXTRACT (도경) ── 마인드맵·요약, 대표 사건 / null 판정
   null이면 여기서 끝                                   ◀ no_event
 │
 ▼
임베딩 ── 기사 앞 800자 → 비슷한 후보 사건 최대 5개
 │
 ▼
② 사건 판정 MATCH_EVENT ── 후보와 비교 → EXISTING / NEW   ◀ 정답셋 (같은 사건·이슈·role)
   NEW면 role · reacts_to 부여
 │
 ▼
③ 이슈 묶기 ── NEW일 때만 ATTACH / CREATE
 │
 ▼
타임라인 ── MAIN → 메인 lane, REACTION → 서브 lane
```

**정답 작성 원칙 [확정]**: 정답은 EXTRACT가 실제로 낸 결과가 아니라 **이 기준으로 사람이 정한다.** 그래야 EXTRACT가 대표 사건을 잘못 골랐을 때도 찾아낼 수 있다.

## 1. 판정 순서 [확정]

**기사별로 먼저 정하고, 그다음 쌍을 판정한다.** 쌍의 정답이 흔들리면 쌍을 보기 전에 두 기사의 사건 유무부터 다시 정한다 (F)

### 1-1. 기사별 (A, B 각각)

| 항목 | 값 |
|---|---|
| `has_event` | `yes` / `no_event` (대표 사건 없음) / `insufficient` (자료 부족으로 대표를 확정할 수 없음) |
| 대표 행위 | 주체 · 행위 · 시점 한 줄 |
| 제외 이유 | `no_event`면 3장의 어느 항목인지 |
| `role` | `main` / `reaction` (7장). `has_event = yes`일 때만 |
| `reacts_to` | `reaction`일 때만 |

### 1-2. 쌍

| 조건 | 라벨 |
|---|---|
| 한쪽이라도 `no_event` | `no_event` (평가 제외) |
| 한쪽이라도 `insufficient` | `uncertain` (평가 제외) |
| 둘 다 대표 사건이 있지만 관계를 판단하기 어려움 | `uncertain` (쌍 단위) |
| 그 외 | `same_event` / `same_issue` / `unrelated` |

## 2. 대표 사건 찾기 [확정]

EXTRACT와 같은 순서로 판단한다.

1. **null인 기사인지 먼저 본다** (3장)
2. 머리말([서울=○○], 앵커 문답, 부제)을 뺀 **제목과 첫 두 문장**에서, 기사가 중심으로 다룬 **한 주체의 완료 행위 하나**를 고른다
3. 그 **행위의 시점**을 본다 (기사 발행일이 아님)

- 배경·계기가 된 행위는 대표 사건이 아니다
- 본문 중간에 잠깐 언급된 내용은 대표 사건이 아니다. 일부 문장이 겹친다는 이유로 판정하지 않는다 (a084, a060, a117)
- 제목에만 있는 정보로 행위를 확정하지 않는다. 본문이 제목을 되풀이하거나 비어 있으면 `insufficient`다 (G)

## 3. 대표 사건 없음 (null) 기준

### 3-1. 항상 null [확정] (EXTRACT 기준)
1. 운세, 시세표, 뉴스 모음
2. 사설, 축사, 기고, 칼럼 (칼럼 코너명 포함, 예: [로터리])
3. 전문가 분석이나 투자 조언만 소개한 기사
4. 일반 정보 설명이나 지난 사례를 다시 짚는 기획. 최근 사건이 도입부에 나와도 null (예: 건강 칼럼)
5. 예정·예고만 다룬 기사: 모집, 행사, 출시, 공연 일정 안내. 단, 새 정책·제도를 정하거나 발표한 기사는 사건

### 3-2. 내용으로 판단 [확정]
- 현상 설명이 중심인 르포·현장 스케치·해설은 null. 개개인의 반응을 세부적으로 다루는 르포 포함 (a096, a215)
- 완료된 행위 자체가 중심이면 형식이 기획이나 르포라는 이유만으로 빼지 않는다
- 분석 기사: **기자가 쓴 분석**은 null, **기관이 공개한 결과**(통계·전망·연구·조사)는 사건

### 3-3. 세부 기준
| 대상 | 기준 | 상태 |
|---|---|---|
| 특징주 등 종목 기사 | 종목 가격 등락·투자 분석을 정리한 기사는 null. 수주·실적 발표처럼 회사의 완료 행위가 중심이면 사건. 시장 전체 지수의 장중·마감 움직임은 예외 ④대로 사건. **코너명이 아니라 중심 내용으로 구분** | [확정] (F) |
| 종합 기사 | 한 주제 아래 여러 주체의 행동을 묶은 기사 (예: "여야 지도부 설 민심 행보"). null 기준을 먼저 보고, 한 주체의 중심 행위를 고를 수 있으면 그 행위로 비교한다. 고를 수 없으면 null | [확정] (D) |
| 부고 | 부고 안내 단신은 null, 한 사람의 사망을 다룬 보도는 사건 | [제안] |
| 인사 | [인사] 명단은 null, 한 사람의 임명 보도는 사건 | [제안] |
| 사진 기사 | 설명으로 완료 행위가 확인되면 판정, 확인되지 않으면 `insufficient` (a110) | [제안] |

## 4. 같은 사건 (`same_event`)

### 4-1. 기본 규칙 [확정]
**같은 주체가 같은 때 같은 자리에서 한 같은 행위**

- 언론사·표현·강조점이 달라도, 다음 날 보도여도 행위가 같으면 같은 사건
- **같은 반응 행위를 다시 보도한 기사도 같은 사건** (같은 성명, 같은 논평)
- 같은 이슈라도 발생 / 수사 결과 / 발표 / 반응 / 다른 날 발언은 **다른 사건**
- 같은 자리라도 주체가 다르면 **다른 사건**
- **같은 주체**: 담당자가 기관의 공식 행위를 대신 전달한 경우(대변인 브리핑, 담당자의 공식 발표 낭독)만 기관과 같은 주체로 본다. 상하 조직(대통령과 계엄사령관, 정부와 소속 부처 차관)이라는 이유만으로는 합치지 않는다 (C)
- **같은 때**: 기사마다 행위 날짜가 하루 다르면 같은 때로 보지 않는다. 시차(현지시간 표기)나 보도 표기 차이처럼 같은 때라고 볼 근거가 기사에 있을 때만 인정한다 (E)
- 같은 주체가 비슷한 말을 했어도 **다른 자리·시점의 발언이면 다른 사건**이고, 같은 이슈인지 따로 판단한다
- "같은 기관 아래", "내용이 비슷함", "입장이 같음"만으로는 같은 사건이 아니다
- 애매하면 다른 사건으로 본다

### 4-2. 예외 (조금 넓게 묶음) [확정]
| 번호 | 규칙 |
|---|---|
| ③ | 한 사람이 같은 자리(국감·회의·기자회견·인터뷰 한 번)에서 한 여러 발언은 **같은 사안에 대한 발언일 때만** 한 사건. 다른 사안에 대한 발언은 따로 본다 (A, a117) |
| ④ | 같은 시장 지표의 같은 거래일 움직임(장중 속보 + 마감) = 한 사건. 다른 지표·개별 종목·다른 거래일은 다른 사건 |
| ⑤ | 같은 날 **같은 행위를 한쪽 기사가 더 자세히 쓴 경우만** 한 사건. 내용이 일부 포함되거나, 비슷하거나, 입장이 같다는 것만으로는 해당하지 않는다. 여러 사건을 모은 종합 기사가 내용을 일부 담는 것도 해당하지 않는다 (B, a084) |

### 4-3. 확정 사례
| 쌍 | 내용 | 근거 |
|---|---|---|
| a166 | 유족 고소 vs 사망 사건·고소 보도 | 같은 사건 서술 |

## 5. 같은 이슈 (`same_issue`) [확정]

**같은 구체적 흐름에 속하지만 별개의 사건**

- 발생 → 수사 → 발표 → 반응 → 후속 조치처럼 이어지는 사건들
- **원 사건과 그에 대한 반응**은 같은 이슈
- 지역·날짜·주체가 달라도 **같은 구체적 계기**에서 나온 일이면 같은 이슈
- 선거·전쟁처럼 오래가는 대형 사안도 하나의 흐름이면 한 이슈. 메인/서브 구분은 관계가 아니라 역할(7장)로 한다

**판단 질문**: 두 사건을 한 타임라인에 이어 놓으면 흐름이 되는가?

| 쌍 | 내용 | 근거 |
|---|---|---|
| a099 | 한동훈 조작 영상 확산 vs 국민의힘 비판 논평 | 같은 사건을 보는 다른 시각 (G로 다시 확인, 4-4) |
| a144 | 라이칭더 당선 vs 미·중 반응 | 원 사건과 반응 |
| a105 | 민주당 특검법 발의 vs 국민의힘 반발 | 발의와 반응 |
| a201 | 오세훈 계엄 직후 집무실 대기(12/3) vs 반대 입장·출장 취소(12/4) | 날짜·행위 다름 |
| a095 | 산불로 막힌 구간 A 통행 재개 vs 구간 B 통행 재개 | 같은 산불에서 파생 |
| a106 | 제3지대 티타임 회동 vs 창준위 출범식 | 주체 같지만 자리 다름 |
| a180 | 경남의사회 반대 vs 대구·경북 의사단체 반발 | 같은 증원 이슈, 다른 단체 |
| a084 | 공수처장 공백·공소 반송 vs 공수처-검찰 갈등 | 공수처 논란 한 흐름 |
| a060 | 이재명 계양 방문 vs 여야 설 민심 행보 | 설 민심 흐름 (D 확정으로 no_event 후보, 4-4) |

## 6. 무관 (`unrelated`) [확정]

**분야·지역·주제·단어만 같고 한 타임라인으로 이어지지 않음**

- 인물·회사·분야가 같다는 이유만으로 묶지 않는다
- 계기는 **특정 사건**이어야 한다. 폭염·저출생 같은 **현상**은 계기가 아니다
- 호우·태풍 같은 기상 사건은 같은 비구름·같은 태풍처럼 **공통 계기가 기사에 적혀 있을 때만** 같은 계기로 본다(→ same_issue). 지역별 특보 발령·해제만 있으면 무관이다. 폭염·장마철처럼 기간 전체에 걸친 현상은 계기가 아니다 (H)
- 서비스 정책(예: 날씨는 이슈로 만들지 않음)은 판정 근거로 쓰지 않는다

| 쌍 | 내용 | 근거 |
|---|---|---|
| a117 | 같은 국무회의의 소방안전 발언 vs 정치 발언 | 같은 자리지만 다른 사안 (A) |
| a081 | 횡성군수 인구 캠페인 vs 경기도 저출생 정책 | 지역·주체 다름, 같은 계기 없음 |

## 7. 역할 (`main` / `reaction`)

**role은 쌍이 아니라 사건(기사)마다 붙는 값이다.** 정답셋에는 `role_A`, `role_B`로 따로 적는다. 마인드맵의 REACTION 가지와는 다른 개념이다.

| 역할 | 해당 행위 | 상태 |
|---|---|---|
| `main` | 정책·제도 결정과 실행 방침 발표, 시행·조치, 기관의 공식 전망·통계·연구·조사 결과 공개, 발생, 파업·사직·고발·소송 제기 | [제안] |
| `reaction` | 다른 사건에 대한 비판·평가·소감·입장 표명·성명·논평 | [제안] |
| 예외 | 새 결정이나 실행 방침을 밝힌 발언은 `main` | [제안] |
| 합의된 예외 | 여론조사 발표, 집회·시위는 `reaction` (a141) | [확정] |

**reacts_to**: 무엇에 대한 반응인지 모르면 `null`. 실제로 이슈 전반을 평가한 반응일 때만 "이슈 전반".

| 쌍 | 판정 | 근거 | 상태 |
|---|---|---|---|
| a141 | 양쪽 reaction | 계엄 선포에 대한 집회 | [확정] |
| a081 | 양쪽 main | 각 지자체의 캠페인 참여·정책 추진 | [확정] |
| a079 | 양쪽 reaction | 공식 발표가 아닌 언급 | 위 [제안] 기준으로 재확인 (금리 인하 "시사"가 새 방침인지) |
| a057 | 양쪽 reaction | 본인 영화에 대한 인터뷰 | 위 [제안] 기준으로 재확인 |
| a161 | 양쪽 main | 전망 발표 | no_event로 다시 판정 중 (4-4). 확정되면 삭제 |

## 8. 11/3 결정 (논의 예정 A~H)

모두 도경 의견대로 정했다.

| 항목 | 결정 | 반영한 곳 |
|---|---|---|
| A. 같은 자리 여러 발언 | 같은 자리라도 같은 사안에 대한 발언만 한 사건, 다른 사안은 따로 | 4-2 ③ |
| B. same_event 범위 | 좁게 유지. 포함 관계는 같은 행위를 한쪽이 더 자세히 쓴 경우만 | 4-2 ⑤ |
| C. 같은 주체의 범위 | 담당자가 기관의 공식 발표를 대신 전달한 경우만 같은 주체. 상하 조직이라는 이유로 합치지 않음 | 4-1 |
| D. 종합 기사 | 한 주체의 중심 행위를 고를 수 있으면 그걸로 비교, 못 고르면 사건 없음 | 3-3 |
| E. 출처 간 날짜 차이 | 자동으로 같은 날로 보지 않음. 시차·보도 표기 차이 같은 근거가 있을 때만 인정 | 4-1 |
| F. null 기준으로 정답 재확인 | 쌍보다 기사별로 사건 유무를 먼저 정함. 특징주 기준 확정 | 1장, 3-3, 4-4 (재검토 리드 시트) |

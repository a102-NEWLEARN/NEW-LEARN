# /deploy-check — 배포 안전 점검

배포는 **되돌리기가 가장 어려운 작업**이다. 순서대로 확인한다.
값은 `.claude/stack.md` §5 L3 · §6 에서 읽는다. 운영 모듈(§9)을 꺼서 *(운영)* 칸이 없으면 그 칸을 짚는 줄은 「해당 없음 — 운영 모듈 꺼짐」으로 적고 넘어간다.

상주 서비스도 배포(패키지 발행 · 스토어 출시 포함)도 없을 때만 "해당 없음" 이라고 답하고 끝낸다.

---

## A. 배포 전

### A-1. 무엇이 나가는지 안다

- [ ] 이번에 들어가는 변경 목록 (`git log`)
- [ ] 🔴 **이 중 되돌릴 수 없는 것이 있나** — 데이터 구조 변경, 파일 삭제, 외부 전송

### A-2. 새 환경변수

- [ ] 코드가 **새로 읽는 값**이 있나
- [ ] 있다면 배포 대상 쪽에 그 값을 **먼저** 채웠나 — 비밀값이면 `.claude/stack.md` §6 「운영 비밀값을 어디에 두나」의 그 자리에 (그 칸이 없으면 어디 넣는지 사람에게 묻는다)

> ⚠️ 이게 가장 흔한 사고다. 예제 파일만 고치고 실제 환경에 안 넣으면
> **프로그램은 정상 기동하고 그 기능만 조용히 죽는다.** 로그에 아무 흔적도 없다.

### A-3. 데이터 구조 변경

- [ ] 이번에 구조를 바꾸나
- [ ] 바꾼다면 🔴 **옛 코드가 새 구조 위에서 돌아도 괜찮은가** — 늘리기 · 코드 · 줄이기를 다른 배포로
      나눴나 (왜는 `.claude/docs/deploy.md` 1절)
- [ ] **이미 적용된 변경 파일을 고치지 않았다** — 주석 한 글자도.
      대개 체크섬으로 검증하므로 고치면 기동부터 실패한다.

### A-3a. 인프라 변경 (인프라를 코드로 둘 때)

- [ ] plan 출력을 읽었다 — 🔴 **지우기(destroy) · 바꿔 끼우기(replace)가 있나.** DB 가 바꿔 끼우기면 데이터가 같이 사라진다
- [ ] apply 는 사람이 승인한다 (`.claude/stack.md` §6 「인프라 변경」의 승인자). AI 는 plan 과 위험한 줄을 보여 주고 멈춘다

### A-4. 옛 클라이언트

- [ ] 응답에서 필드를 빼거나 이름을 바꿨나 → **아직 안 갈아탄 앱·클라이언트가 깨진다**

### A-5. 되돌리는 법

- [ ] `.claude/stack.md` §6 의 되돌리는 명령을 **지금 여기에 적어 둔다**
- [ ] 되돌려도 **안 돌아오는 것**을 안다 (보통 데이터 구조 변경)

아래 둘은 못 채워도 배포를 막지 않는다. 대신 보고에 적는다.

- [ ] 되돌리는 법을 실제로 돌려 본 적이 있다 (없으면 보고에 「첫 실전」)
- [ ] 무엇이 보이면 되돌릴지 적었다 (예: L3 실패)

---

## B. 배포

- [ ] 🔴 **배포 명령은 사람이 확인한 뒤 실행한다** (`.claude/HARNESS.md` 7절). AI 는 명령과 되돌리는 법을 보여 주고 멈춘다
- [ ] `.claude/stack.md` §6 의 트리거/명령대로 한다. 손으로 다른 방법을 쓰지 않는다
- [ ] 배포가 **성공으로 끝났는지** 확인 (로그·상태)

---

## C. 배포 후 — `/health-check` L3

- [ ] **헬스 주소 말고 실제 기능을 부른다** — 서버면 실제 API, 패키지면 깨끗한 환경에 방금 낸 버전을 설치해 돌린다
- [ ] 떠 있는 버전이 이번에 올린 태그인가 (`.claude/stack.md` §5 L3 「떠 있는 버전 확인」)
- [ ] 정상 판정 기준(`.claude/stack.md` §5 L3)과 대조
- [ ] 로그에 새 에러가 없나 (몇 분간 — 보는 곳은 `.claude/stack.md` §5 L2 「로그 · 지표 · 추적을 보는 곳」. 그 칸이 없으면 배포 대상의 로그를 직접 본다)
- [ ] 배포 이력에 남았나 (`.claude/stack.md` §6 「배포 이력이 남는 곳」). 되돌릴 때 이 기록에서 옛 태그를 찾는다

**이상하면 고치려 들지 말고 먼저 되돌리기를 제안한다.** 사람이 확인하면 되돌린다. 원인 조사는 되돌린 다음에 한다.

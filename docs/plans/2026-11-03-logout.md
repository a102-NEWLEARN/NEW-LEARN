# S15P31A102-66 로그아웃 — 마이페이지 첫 판

## 무엇을 / 왜

로그인 MR(`c1b1512`, frontend 에 머지)은 로그인과 원래 화면 복귀까지였다. 로그아웃이 남아 Jira -66 이 「진행 중」이다.
로그아웃 버튼은 마이페이지(`/me`)에 있는데 마이페이지가 아직 없다. 헤더 *마이페이지* 와 홈 *관심사 편집* 을 누르면 찾을 수 없음 화면이 뜬다.
**F12 회원·관심 분야의 로그아웃**을 하려고 마이페이지 첫 판을 만든다. 프로토타입 v21 `MyPageScreen` 을 따른다.
머지되면 Jira -66 을 Done 으로 옮긴다.

## 정한 것 (사용자가 볼 것)

- 마이페이지 첫 판 — 머리 줄(이름 첫 글자 원 · 「OO님」), 개인정보(이름 · 아이디, 바꿀 수 없다), *로그아웃*
- **로그아웃 뒤 갈 곳: 랜딩(`/`)** 과 스낵바 「로그아웃했어요」 — EXPERIENCE.md 「아직 정하지 않은 것」의 행을 닫는다
  - 손님은 로그인부터라 셸 안 화면에 남을 수 없다. 남기면 가드가 곧바로 로그인 화면으로 보낸다
  - 손님이 처음 서는 곳이 랜딩이다. `dev:mock` 도 손님이 되면 랜딩부터 시작한다
  - 프로토타입 문구의 「둘러보기는 계속할 수 있어요」는 뺀다. 손님은 둘러볼 수 없다
- 세션이 이미 끊겼으면(A16 401) 로그아웃한 것과 똑같이 한다 — 끊으려던 세션이 이미 없다
- 그 밖의 실패는 버튼 아래에 안내를 띄우고 마이페이지에 남는다 (State Patterns — 오류는 그 자리에)
- 로그아웃하면 이전 회원의 캐시를 모두 버린다 — 기사 · 이슈 응답의 `bookmarked` · `interested` 가 회원 기준이다

## 리스크

- **잘못된 본문 거르기가 약해진다** — 같은 본문 3건이 30분 안에 모여야 걸린다. 창이 겹쳐 한 번 걸러진 기사가 다음 실행에서 3건 밑으로 줄면 그대로 들어온다. 재 보지 않았다. 사흘이라 들어온 것은 제보받아 라벨로 숨긴다
- **NewsData 지연** — 발행 뒤 30분이 지나 올라오는 기사는 놓친다. 잰 적 없다. 11/16 에 시간대별 수와 지난주 같은 요일을 견준다
- **연속 실패** — 재시도가 없고 창이 30분이라 두 번 연속 실패하면 그만큼 빠진다. 경보(약 35분)가 오면 손 실행으로 메운다. 손 실행 성공은 경보를 최대 30분 가릴 수 있다
- **`timeframe=30m` 은 실제로 보낸 적이 없다** — 지금 받기만 한 번(`fetch-only`, 1크레딧)으로 확인한다. 거절되면 값을 시간 단위로 바꾼다
- **머지가 자동 권한 검사에 막히면** 사용자가 누른다
- **머지 전에 다른 MR 이 같은 문서를 고침** — Draft 를 11/16 에 최신 `infra` 와 합친다

- 섹션 차례 개인정보 → 관심 분야 → 관심 이슈. *로그아웃* 은 이름 줄 오른쪽 작은 테두리 버튼. 실패 안내는 그 아래
- 관심 분야 *저장* 은 카드 제목 오른쪽(`MyPageSection` 의 `action`). 저장하면 알림을 띄우고 마이페이지에 남는다 — 카드 위 버튼이 다른 화면으로 넘어가면 놀란다. 가운데 저장 줄(안내 · *홈으로* · *저장하고 홈으로*)은 없앴다
- 이름 줄 개수가 로그아웃 때문에 좁아져 「북마크 / 3개」로 갈라졌다 — 이슈 머리와 같은 처리를 `lib/meta.ts` 의 `metaLine` 으로 떼어 둘이 같이 쓴다
- 시험: 섹션 차례 · 로그아웃 자리 1, `metaLine` 2. 관심 분야 시험은 저장 뒤 홈으로 → 마이페이지에 남기로 고치고 *홈으로* 시험을 지웠다
- 문서: EXPERIENCE IA 마이페이지 행

## 5차 — 로그아웃을 헤더 프로필 메뉴로 (같은 날, 사용자 「로그아웃이 이름 줄에 있는 게 이상하다」)

세 안(개인정보 카드 맨 아래 / 헤더 프로필 메뉴 / 페이지 맨 아래 작은 글자)을 보여 주고 사용자가 **헤더 프로필 메뉴**를 골랐다. 넓은 화면 버튼 글자는 「마이페이지 ▾」 그대로.

- 헤더 *마이페이지* 를 링크에서 메뉴 버튼으로(`ProfileMenu.tsx`, SEED `Menu`). 항목 *마이페이지* · *로그아웃*. 지금 화면 모양은 `data-current`, 화면 읽기는 메뉴 안 *마이페이지* 의 `aria-current`
- 로그아웃 동작은 `useLogout.ts` 로 떼어 옮겼다(랜딩 · 받아 둔 응답 버림 · 「로그아웃했어요」 · 두 번 안 보냄 그대로). 마이페이지에서는 뺐다
- 로그아웃을 누르면 메뉴를 열어 둔다 — SEED 메뉴는 항목 onClick 다음 itemClick 으로 닫아서, 그 닫힘만 무시한다. 실패하면 메뉴 안 로그아웃 아래에 안내(오류는 스낵바가 아니라 실패한 자리 — `useSnackbar`). 그새 닫았으면 다시 연다
- 시험: 마이페이지 로그아웃 시험 7개를 `ProfileMenu.test.tsx` 로 옮기고 메뉴 열기 · 마이페이지 항목 · Esc 를 더했다(10). 닫힌 메뉴는 DOM 에 남고 SEED CSS(`[data-hidden]`)가 숨겨서, jsdom 에서는 버튼 `aria-expanded` 로 닫힘을 본다

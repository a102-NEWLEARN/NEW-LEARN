# S15P31A102-31 앱 셸

> 2026-10-23 사용자가 자리를 비운 동안 「알아서 다 해놔」로 맡겨 진행했다. 승인 화면을 거치지 않았으니 돌아와서 「사용자가 볼 것」부터 확인받는다.

## 무엇을 / 왜

로그인 뒤 화면(홈 · 이슈 · 기사 · 마이페이지)은 모두 같은 틀 안에 뜬다 (EXPERIENCE.md 앱 셸). 홈(-44)부터 화면을 만들려면 틀이 먼저 있어야 해서 -31 의 남은 반쪽인 셸을 만든다. 기준은 EXPERIENCE.md(v21) · DESIGN.md · 프로토타입 v21 이다.

브랜치: `git nb feat frontend 31 app-shell` (origin/frontend) + 아직 머지 전인 -31 상태 MR 브랜치를 합친다. -31 MR 이 머지되면 이 MR 에는 셸 커밋만 남는다.

## 만들 구조

```
frontend/src/
├─ routes.tsx                     ✏️ "/" → /home 로 보냄(랜딩은 -44) · 셸 레이아웃 라우트 · 오류 화면
├─ App.tsx                        ✏️ 개발 확인 화면에서 헤더 · <main> 을 빼고 /home 자리로 (홈은 -44 에서 바뀜)
├─ api/
│  ├─ error.ts                    ✏️ isNetworkError — 서버에 못 닿은 요청만 네트워크 안내
│  ├─ categories.ts               ✏️ 화면이 덧붙이는 준비 중 분야 두 개(스포츠 · 문화/연예)
│  └─ issues.ts                   🆕 A2 이슈 목록 — 호출 · 타입 · query
├─ mocks/handlers.ts              ✏️ A2 가짜 응답 (분야로 거름)
├─ components/
│  ├─ state/ErrorState.tsx        ✏️ 위 isNetworkError 를 씀
│  └─ shell/                      🆕
│     ├─ AppShell.tsx               헤더 + 사이드바(또는 서랍) + <main><Outlet/></main>. 접힘 · 서랍 상태와 ⌘/Ctrl+\
│     ├─ Header.tsx                 메뉴(좁을 때) · 로고 · 나의 뉴스함(곧 제공) · 마이페이지
│     ├─ Sidebar.tsx                접힘 64px 레일 ↔ 펼침 216px. 펼친 내용(SidebarMenu)은 서랍과 같이 쓴다
│     ├─ SidebarDrawer.tsx          767px 이하 서랍 — SEED SidePanel(왼쪽, 280px)
│     ├─ IssueExplorer.tsx          이슈 탐색 — 분야 → 연도 → 이슈
│     ├─ useMediaQuery.ts           767px 이하인지
│     └─ *.test.tsx
├─ pages/RouteErrorPage.tsx       🆕 화면이 렌더 중 터졌을 때 (셸은 남기고 본문 자리에)
└─ test/
   ├─ media.ts                    🆕 matchMedia 흉내 (jsdom 에 없다). 기본 넓은 화면
   ├─ setup.ts                    ✏️ 넓은 화면으로 둔다
   └─ render.tsx                  ✏️ renderRoute 가 라우트 목록을 받고 router 를 돌려준다
```

접힘 · 서랍 상태는 셸 하나만 써서 Zustand 저장소 대신 `AppShell` 의 상태로 뒀다. 오른쪽 패널(-52)이 사이드바를 접어야 할 때 저장소로 옮긴다.

| `/home` | 개발 확인 화면 | 홈은 -44. 그전까지 셸을 눈으로 볼 자리 |

| 빠른 이동 | 곧 제공 | 통합 검색이 MVP 미정 (EXPERIENCE IA, Jira -46) |

| 이슈 탐색 깊이 | 분야 → 연도 → 이슈까지. 사건은 이슈 화면(-50)이 생길 때 | 사건 목록은 A4(이슈별 타임라인)라 지금 쓸 화면이 없다 |

## 안 바꿀 것

- 오른쪽 패널(사건 패널, -52) · 용어사전 버튼과 창(F13 제안, A19 백엔드 아직) — 그 화면 티켓에서
- 랜딩 · 로그인 · 가입 · 손님 막기(-44 · -66), ⌘/Ctrl+K
- 사이드바 폭 끌어 바꾸기 (EXPERIENCE 가 뺐다)
- `seed-design/ui/` · DESIGN.md · EXPERIENCE.md

## 리스크

- 헤더 · 사이드바를 SEED SideNavigation 대신 보통 요소 + SEED 토큰으로 만든다. SideNavigation 은 폭(240/56)과 1280px 자동 접힘이 EXPERIENCE 와 달라 덮어쓸 곳이 많다
- jsdom 에 `matchMedia` 가 없다 — 테스트 준비에 넓은 화면으로 흉내 낸다
- 셸 안에서 본문만 스크롤한다(프로토타입과 같다). 화면을 옮길 때 스크롤 위치는 아직 안 다룬다

## 어떻게 검증하나

- `frontend/` 에서 포맷 · 린트 · 테스트 · 빌드 (`.claude/stack.md` §3)
- 새 테스트: 라우트(`/` → `/home`, 셸 안의 찾을 수 없음, 오류 화면), 헤더(로고 → /home, 곧 제공), 사이드바(처음 접힘, 버튼 · Ctrl+\ 로 펼침, aria-expanded, 홈 aria-current), 이슈 탐색(분야 → 연도 → 이슈, 준비 중 안내, 불러오기 실패), 좁은 화면 서랍(열기 · Esc · 항목 고르면 닫힘), isNetworkError
- 화면: `dev:mock` 을 헤드리스 Chrome(DevTools 프로토콜)으로 1280 · 375 폭에서 찍어 `.notes/mr/S15P31A102-31-shell/`

- 화면을 옮길 때 `<title>` 바꾸기와 포커스를 맨 위 제목으로 옮기기 (EXPERIENCE Accessibility Floor `[가정]`) — 실제 화면이 생기는 -44 에서 셸과 함께 넣는다

- 빌드 JS 가 434 → 521 kB(gzip 139 → 165 kB)로 커져 Vite 500 kB 경고가 뜬다. 서랍(SEED SidePanel)을 좁은 화면에서만 불러오면(lazy) 줄일 수 있다 — 사용자에게 묻는다
- 실제 스크린 리더(NVDA · VoiceOver)로는 듣지 않았다

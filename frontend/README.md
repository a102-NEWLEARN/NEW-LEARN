# frontend

NEW:LEARN 화면(React)이다. 개발 서버는 `npm run dev` 면 진짜 API(백엔드)로, `npm run dev:mock` 이면 가짜 API 로 띄운다 (아래 「가짜 API」).
쓰는 기술은 `.claude/stack.md` §2, 설치 · 개발 서버 · 포맷 · 린트 · 테스트 · 빌드 명령은 §3 에 있다.
화면이 어떻게 동작하는지는 EXPERIENCE.md, 어떻게 보이는지는 DESIGN.md 가 정한다 (`.claude/stack.md` §7 「화면 · 이동」 · 「디자인」).

## 폴더

| 폴더              | 무엇                                                                                             |
| ----------------- | ------------------------------------------------------------------------------------------------ |
| `src/pages/`      | 주소 하나에 화면 하나 (`HomePage.tsx`)                                                           |
| `src/components/` | 여러 화면이 같이 쓰는 컴포넌트 (셸 · 상태 · `Logo`). 한 화면의 조각은 그 화면 이름 폴더(`home/`) |
| `src/lib/`        | 화면과 상관없는 도우미 (날짜 표기)                                                               |
| `src/api/`        | 클라이언트 · 오류 · 목록 타입, 엔드포인트마다 파일 하나 (호출 함수 · 타입 · query key)           |
| `src/mocks/`      | 가짜 API(MSW) 핸들러 · 가짜 데이터. `snapshot/` 은 Vercel 데모의 실제 기사 스냅샷                |
| `src/test/`       | 테스트 설정 · 도우미                                                                             |
| `seed-design/ui/` | SEED CLI 가 내려받는 컴포넌트. 손대지 않는다                                                     |

테스트는 대상 파일 옆에 `*.test.ts(x)` 로 둔다.

상태는 전역 저장소에 두지 않는다. 서버 데이터는 TanStack Query 캐시, 고른 사건 · 보기 · 탭 · 쪽은 주소(`useSearchParams`), 그 밖은 쓰는 컴포넌트의 상태다. 처음에 넣었던 Zustand 는 쓸 곳이 없어 2026-11-16 뺐다.

## import

`src/` 아래 파일은 `@/` 로 부른다 (`import { api } from "@/api/client"`). SEED CLI 컴포넌트는 `seed-design/ui/…` 다.

## 가짜 API

화면은 가짜 API(MSW — 브라우저와 테스트에서 요청을 가로채 정해 둔 응답을 돌려주는 도구)로 만든다.

| 무엇                       | 어떻게                                                                                                                                                                                                                                                                                                                                                                              |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 가짜 API 를 켠 개발 서버   | `npm run dev:mock`. `npm run dev` 는 가짜 API 없이 진짜 API(백엔드)로 보낸다                                                                                                                                                                                                                                                                                                        |
| 진짜 API 로 띄운 개발 서버 | `npm run dev`. 로컬 백엔드는 루트 `.env` 의 `BACKEND_PORT` 로 찾는다. 배포 서버로 보내려면 `API_PROXY_TARGET=https://newlearn.io.kr npm run dev` — 팀이 같이 쓰는 서버라 가입 · 북마크처럼 데이터를 만드는 요청은 조심한다                                                                                                                                                          |
| 응답                       | `src/mocks/handlers.ts`. 모양은 `docs/api-screen.md` 예시를 따르고 값은 지어낸다                                                                                                                                                                                                                                                                                                    |
| 로그인 상태                | `npm run dev:mock` 화면은 열 때마다 손님으로 랜딩부터 시작한다. 아무 아이디 · 비밀번호로 로그인하면 회원이 되고, 새로 고치거나 다시 열면 손님이다 (`src/mocks/session.ts`). 테스트는 이것을 쓰지 않아 늘 회원이다                                                                                                                                                                   |
| 용어사전                   | 문맥 뜻(A26 `POST /api/v1/dictionary/meaning`)도 가짜로 답한다 — 진짜는 로그인 세션과 GMS 키가 있어야 해서다. 가짜는 409 기사의 경제 용어(이자 · 기준금리 · 역레포 …)만 알고 화면에서는 1.2초 기다려 점 셋을 보인다(`src/mocks/handlers.ts`). 모르는 말은 「풀이 불가」다                                                                                                           |
| 테스트                     | 같은 핸들러를 쓴다 (`src/mocks/node.ts`). 핸들러가 없는 요청은 테스트를 실패시킨다. 한 테스트에서만 응답을 바꾸려면 `server.use(…)`                                                                                                                                                                                                                                                 |
| 빌드                       | `npm run build` 결과에는 가짜 API 가 들어가지 않는다. `npm run build -- --mode mock`(목 빌드) · `--mode demo`(데모 빌드)이면 들어가고, 폰 설치용 서비스 워커는 등록하지 않는다 — 같은 자리를 MSW 워커가 쓴다 (`src/pwa/registerServiceWorker.ts`)                                                                                                                                   |
| Vercel 데모                | 서버 없이 보는 데모다 (Jira S15P31A102-220). Vercel 이 GitHub 공개 미러의 `frontend` 브랜치를 데모 빌드(`--mode demo`)로 올린다. 빌드 설정은 `vercel.json` 에 있고, Vercel 화면에서는 Root Directory 만 `frontend` 로 둔다. 로컬에서는 `npm run dev:demo`                                                                                                                           |
| 데모의 데이터              | 실제 기사 스냅샷이다 (`src/mocks/snapshot/`). 2026-11-16 newlearn.io.kr 공개 API 에서 홈 이슈 16개와 그 사건 180개 · 기사 1,938건 · 마인드맵을 받았다. 본문은 없다(API 가 주지 않는다). 서버가 내려가 다시 받을 수 없으니 `data/` 는 손대지 않는다. 회원 · 로그인 · 용어사전은 위 가짜 API 그대로이고, 북마크 · 관심 이슈는 열 때마다 비어 있다. 스냅샷에 없는 이슈 · 기사는 404 다 |

진짜 응답은 `npm run dev` 로 확인한다. 핸들러는 테스트가 계속 쓴다.
